如何构建
在资源管理器地址栏或 PowerShell 打开项目根目录 进入仓库目录 构建： .\gradlew.bat build 或 .\gradlew.bat clean build

Jar 输出: 位于 build/libs/ 内


How to Build
Open the project root directory in the address bar of File Explorer or via PowerShell. Navigate to the repository directory. Build: .\gradlew.bat build or .\gradlew.bat clean build

Jar output: Located in build/libs/
